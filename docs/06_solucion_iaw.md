# Solución de Implantación de Aplicaciones Web (IAW)

## 1. Descripción de la solución

La solución propuesta consiste en diseñar e implementar una aplicación web interna para la asesoría informática que permita gestionar de forma organizada la información relacionada con sus clientes y los servicios que ofrece.

La aplicación estará desarrollada utilizando HTML y CSS para la interfaz, PHP para la parte del servidor y MySQL como sistema gestor de bases de datos.

La aplicación permitirá gestionar clientes, servicios, incidencias y proyectos, además de consultar la información almacenada en la base de datos.

La aplicación web estará conectada con la base de datos definida en la solución de ASGBD, permitiendo utilizar la información almacenada de forma centralizada.

## 2. Funcionalidades de la aplicación

La aplicación web dispondrá de diferentes funcionalidades para facilitar la gestión de la información de la asesoría.

Las principales funcionalidades serán:

1. **Gestión de clientes:** permitir consultar, añadir, modificar y eliminar la información de los clientes.
2. **Gestión de servicios:** permitir consultar, añadir, modificar y eliminar los servicios ofrecidos por la asesoría.
3. **Gestión de incidencias:** permitir registrar, consultar, modificar y cerrar las incidencias comunicadas por los clientes.
4. **Gestión de proyectos:** permitir consultar, crear, modificar y finalizar los proyectos gestionados por la asesoría.
5. **Consulta de información:** permitir consultar de forma organizada la información almacenada en la base de datos.

Estas funcionalidades permitirán centralizar la gestión de la información y facilitar el trabajo del personal de la asesoría.

## 3. Integración con la base de datos

La aplicación web se conectará con la base de datos MySQL definida en la solución de ASGBD para utilizar la información almacenada de forma centralizada.

La aplicación permitirá realizar las principales operaciones de gestión de datos:

- **Consultar** información almacenada.
- **Añadir** nuevos registros.
- **Modificar** registros existentes.
- **Eliminar** registros cuando sea necesario.
- **Relacionar** la información de clientes, servicios, incidencias y proyectos.

La conexión entre la aplicación web y la base de datos permitirá que la información gestionada desde la aplicación se almacene de forma centralizada y pueda ser consultada posteriormente por el personal autorizado.

## 4. Comprobación del funcionamiento

Una vez implementada la aplicación web, se realizarán diferentes pruebas para comprobar que sus principales funciones funcionan correctamente.

Las comprobaciones serán:

1. Comprobar que la aplicación se puede abrir y utilizar correctamente.
2. Comprobar que se pueden consultar los clientes y servicios almacenados.
3. Comprobar que se pueden añadir nuevos clientes, servicios, incidencias y proyectos.
4. Comprobar que se pueden modificar los datos existentes.
5. Comprobar que se pueden eliminar o cerrar los registros correspondientes.
6. Comprobar que los cambios realizados desde la aplicación se almacenan correctamente en la base de datos.
7. Comprobar que la información relacionada entre las diferentes entidades se muestra correctamente.

Estas pruebas permitirán verificar que la aplicación web funciona correctamente y que permite gestionar la información de la asesoría de forma adecuada.
